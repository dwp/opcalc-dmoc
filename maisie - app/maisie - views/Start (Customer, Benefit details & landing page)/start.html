OpCalc

Use OpCalc to work out a customer's benefit entitlement based on their income, savings and household circumstances.

Use this service to:

  • open an existing case or start a new one
  • record customer, appointee and household details
  • calculate entitlement for benefits including Income Support, Jobseeker's Allowance, Employment and Support Allowance, Pension Credit and State Pension
  • work out income, housing costs, non-dependant deductions and diminishing capital
  • generate supporting forms, such as A14, BA3 and QB16

Before you start

If you're opening an existing case, you'll need the case reference number.

For a new case, you'll need the customer's benefit type and details of their income, savings, housing costs and any non-dependants living with them.

If you're not sure which forms a benefit type needs, check the list of benefit types and forms before you start.
