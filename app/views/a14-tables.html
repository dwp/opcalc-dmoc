{# app/views/a14-tables.html One macro that renders any of the A14 tables from what routes.js has stored, so the six tables across the three A14 forms all behave the same way. Use it by importing at the top of an A14 form page, below the extends line: {% from "a14-tables.html" import a14Table %} Then replace a static govukTable with a call. For the benefit weeks table on the BWE/BWC tab: {{ a14Table( data.a14BenefitWeeks, [ { text: "Start date", field: "bwDateOfChange" }, { text: "Pay day", field: "benefitPayDay" }, { text: "Ben week", field: "benefitWeekType" }, { text: "Part week(s)", field: "partWeeks" } ], "No benefit weeks recorded", "a14BenefitWeeks", "/A14pcispc/a14#bwe-bwc" ) }} The arguments are: rows the stored array - data.a14BenefitWeeks, data.a14Exclusions, data.a14Benefits, data.a14OtherIncome, data.a14Dependants, data.a14NonDependants columns what to show, in order. field is the name attribute of the input on the sub-page. A date input's three fields are also joined under its prefix, so use the prefix rather than -day. Add prefix: "£" to a column to put a symbol in front of the value, so a money column reads £86.40 rather than 86.40 emptyText the line shown when nothing has been added yet key the same array name again, so Delete knows what to remove from returnTo where Delete comes back to - this page and tab deletePath optional. A confirmation page to send Delete to, instead of deleting the row there and then. The table and the row number go with it, so one page can confirm any row If a column is blank when you expect a value, the field name does not match the input on the sub-page. Add ?show-fields=yes to the page address to list the field names actually stored against each row. #} {% from "govuk/components/table/macro.njk" import govukTable %} {% from "govuk/components/details/macro.njk" import govukDetails %} {% macro a14Table(rows, columns, emptyText, key, returnTo, deletePath) %} {% set list = rows if rows else [] %} {# The Actions column only appears once there is a row to act on, so an empty table does not carry a header for something that is not there. #} {% set head = [] %} {% for column in columns %} {% set _ = head.push({ text: column.text }) %} {% endfor %} {% if list | length and key %} {% set _ = head.push({ text: "Actions" }) %} {% endif %} {% set tableRows = [] %} {% for row in list %} {% set cells = [] %} {% for column in columns %} {% set names = column.field if column.field is iterable and column.field is not string else [column.field] %} {% set found = [] %} {# 1. The field name exactly as configured. #} {% for name in names %} {% if row[name] and not found | length %} {% set _ = found.push(row[name]) %} {% endif %} {% endfor %} {# 2. Sub-pages prefix their fields - esaExclusionFrom rather than exclusionFrom, isjsaBenefitAmount rather than benefitAmount. So if nothing matched exactly, take any field whose name contains the one configured. Fields holding a single part of a date are skipped, so a date column shows 05/05/2003 rather than just the 05. #} {% if not found | length %} {% for name in names %} {% for field, value in row %} {% if not found | length and value and field[0] != "_" and "-" not in field and (name | lower) in (field | lower) %} {% set _ = found.push(value) %} {% endif %} {% endfor %} {% endfor %} {% endif %} {% set shown = (column.prefix if column.prefix else "") + found[0] if found | length else "" %} {% set _ = cells.push({ text: shown }) %} {% endfor %} {% if key %} {# Edit reopens the sub-page this entry was made on, prefilled. Rows saved before Edit existed have no page recorded, so they only offer Delete - add them again and Edit appears. #} {% set actions = [] %} {% if row._page %} {% set _ = actions.push('Edit row ' + loop.index + '') %} {% endif %} {# With a deletePath the row is not removed yet - you get a page asking whether you meant it, which is right for something that cannot be undone. Without one, Delete removes the row straight away, which is how the A14 tables have always worked. #} {% if deletePath %} {% set _ = actions.push('Delete row ' + loop.index + '') %} {% else %} {% set _ = actions.push('Delete row ' + loop.index + '') %} {% endif %} {% set _ = cells.push({ html: actions | join(' | ') }) %} {% endif %} {% set _ = tableRows.push(cells) %} {% endfor %} {% if not list | length %} {% set cells = [{ html: '' + emptyText + '' }] %} {% for column in columns %} {% if not loop.first %} {% set _ = cells.push({ text: "" }) %} {% endif %} {% endfor %} {% set _ = tableRows.push(cells) %} {% endif %} {{ govukTable({ head: head, rows: tableRows }) }} {% endmacro %} {# Lists the field names stored against each row, so a column that comes out blank can be matched to the right input name. Add ?show-fields=yes to the page address to see it. #} {% macro a14Fields(rows, title) %} {% set list = rows if rows else [] %} {% if list | length %} {{ govukDetails({ summaryText: "Field names stored for " + title, html: '' + (list[0] | dump) + '' }) }} {% endif %} {% endmacro %}
